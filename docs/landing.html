pitop

A terminal-based system monitor for Raspberry Pi, written in Rust.
Think htop meets mactop — purpose-built for Pi hardware.

Install

curl -sL https://pitop.hongjunwu.com/install.sh | sh

That's it. The script auto-detects your Pi model and architecture, downloads the right binary, and installs it to /usr/local/bin.

Pin a specific version:

curl -sL https://pitop.hongjunwu.com/install.sh | PITOP_VERSION=v0.1.0 sh

Other ways to install

cargo install

If you have Rust installed:

cargo install --git https://github.com/wu-hongjun/pitop

Build from source

git clone https://github.com/wu-hongjun/pitop
cd pitop
cargo build --release
sudo cp target/release/pitop /usr/local/bin/

Install Rust first

If you don't have Rust on your Pi:

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source ~/.cargo/env

Download binary

Grab a release tarball directly from GitHub Releases.

tar xzf pitop-v*.tar.gz
sudo mv pitop /usr/local/bin/

Quick start

# Launch
pitop

# Start on the Power tab
pitop --tab 3

# Solarized theme, 500ms refresh
pitop --theme solarized --interval 500

# Stress test your Pi
pitop --stress

# Generate a config file
pitop --generate-config > ~/.config/pitop/config.toml
